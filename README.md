# ETL Pipeline — Amman Digital Market

## Overview

This ETL pipeline extracts data from the Amman Digital Market PostgreSQL database, filters out cancelled orders and suspicious quantities, aggregates customer order metrics, and outputs the results to `customer_analytics.csv`.  
It provides insights into customer behavior and sales performance.


## Setup

1. Start PostgreSQL container:
   ```bash
   docker run -d --name postgres-m3-int \
     -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres \
     -e POSTGRES_DB=amman_market \
     -p 5432:5432 -v pgdata_m3_int:/var/lib/postgresql/data \
     postgres:15-alpine
   ```
2. Load schema and data:
   ```bash
   psql -h localhost -U postgres -d amman_market -f schema.sql
   psql -h localhost -U postgres -d amman_market -f seed_data.sql
   ```
3. Install dependencies: `pip install -r requirements.txt`

## How to Run

```bash
python etl_pipeline.py
```

## Output


The pipeline generates a CSV file customer_analytics.csv containing:

customer_id: Unique identifier for the customer
customer_name: Customer's full name
city: Customer's city
total_orders: Total number of completed orders
total_revenue: Total revenue generated by the customer
avg_order_value: Average value per order
top_category: Most purchased product category

This file can be used for analytics, reporting, and business decision-making.


## Quality Checks

The ETL pipeline performs the following validations to ensure data quality:

Exclude cancelled orders — Ensures only completed sales are analyzed.
Exclude suspicious quantities (>100) — Removes potentially erroneous data that could skew metrics.
Null checks — Raises errors if critical fields like customer_id are missing.
Aggregated metrics validation — Confirms totals, averages, and top categories are calculated correctly.

These checks prevent inaccurate insights and maintain integrity of the analytics.
